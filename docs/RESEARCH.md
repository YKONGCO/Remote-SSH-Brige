## 数据流

GUI invoke / MCP tools → 共享 execute → 服务器启用状态与 MCP 权限 → SSH 主机指纹 → 账户认证 → exec / SFTP / PTY → 审计。

- SSH 密码与私钥口令放在系统凭据库；配置只保存主机信息与私钥路径。
- 本机 MCP 使用 Streamable HTTP、Bearer Token、127.0.0.1 监听，并拒绝浏览器 Origin。
- 文件根目录校验解析已有路径和新文件父路径，阻止常见的 ..、跨根目录和符号链接越界。远端拥有写权限的其他进程仍可能制造路径检查与操作之间的竞态；该功能不是操作系统级沙箱。
- exec / PTY 本身拥有 SSH 账户的 shell 权限，不受 SFTP 文件根目录限制。界面、工具说明与 README 都明确表达此边界。
- 终端在应用进程存活且 SSH 连接正常时持续运行。跨断线、跨应用重启恢复应增加远端 tmux 或类似机制，当前版本没有宣称具备该能力。
- 文件保存使用同目录临时文件 + 原子重命名，保留原文件的权限位；替换文件可能改变其所有者、ACL、扩展属性或硬链接关系。服务端需支持原子重命名。
- MCP 不提供配置服务器或获取凭据的工具；服务器管理只能在本机界面进行。

## 本版范围

已有：服务器增改删与分组、密码/私钥/Agent 认证、指纹核验、MCP 启停、16 个工具（包括服务器与会话发现）、命令执行、文件管理、文本编辑、单文件传输、共享终端、可导出审计。

未实现：跳板机、SSH config 导入、代理、断线重连、tmux 恢复、递归目录传输、数据库管理、远程公开 MCP、逐操作审批、命令 OS 级沙箱。
