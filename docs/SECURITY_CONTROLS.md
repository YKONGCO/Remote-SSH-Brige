# 安全控制与文件预览

在「设置 → 安全控制」中分别配置，设置保存到本机 SQLite。旧配置会补齐以下默认值：

| 功能         | 默认值 | 范围                                                                                 |
| ------------ | ------ | ------------------------------------------------------------------------------------ |
| 删除保护     | 开启   | 桌面与 MCP 的远程文件、目录删除                                                      |
| 危险命令拦截 | 开启   | 拦截可静态解析的删除、磁盘破坏、关机等已知高危 Shell 命令；Shell 功能另行授权        |
| 只读保护     | 关闭   | 禁止文件修改、命令执行、终端打开和输入，允许查看、下载、读取输出、调整尺寸与关闭终端 |
| 审批模式     | 关闭   | 可选择「仅 MCP 敏感操作」或「所有来源的敏感操作」                                    |

所有操作通过后端共同入口校验，前端按钮禁用仅作提示。MCP 原有服务器权限、主机指纹和文件根目录限制继续生效。文件传输大小在排队审批前检查；审批不能覆盖删除保护、只读保护或命令拦截。

## 命令保护

在「设置 → 命令与 Shell 权限」中分别配置：

| 开关              | 新安装默认值 | 范围                                                                |
| ----------------- | ------------ | ------------------------------------------------------------------- |
| 仅允许诊断命令    | 开启         | 每个执行节点须为诊断白名单中的命令；关闭后允许其他命令名            |
| 允许管道          | 关闭         | `ls \| head`、`\|&`；每个管道命令分别检查                           |
| 允许重定向        | 关闭         | `>`、`>>`、`<`、`2>&1`、here-document、here-string                  |
| 允许组合命令      | 关闭         | 分号、换行、`&&`、`\|\|`、后台执行、命令分组                        |
| 允许脚本执行      | 关闭         | Shell / Python 等解释器、脚本路径、变量和控制结构；需关闭诊断白名单 |
| 允许命令替换      | 关闭         | `$(...)`、反引号、进程替换；内层 Shell 命令照常检查                 |
| 允许 MCP 交互终端 | 关闭         | MCP 打开终端和发送输入；仍须对应服务器权限                          |

例如，允许管道但保持诊断白名单时，`ls | head` 可执行，`ls | grep error` 仍因 `grep` 不在白名单被拒绝。关闭诊断白名单后可以执行 `grep`；无须关闭高危拦截。只开启管道不会顺带允许重定向、脚本或组合命令。

诊断白名单包括：`pwd`、`ls`、`cat`、`head`、`tail`、`stat`、`file`、`du`、`df`、`free`、`uptime`、`whoami`、`id`、`uname`、`date`、`hostname`、`ps`、`ss`、`netstat`、`wc`、`readlink`、`realpath`。允许不带路径的命令和 `/bin/`、`/usr/bin/` 下的同名命令，并拒绝修改日期、修改主机名、终止网络连接和编译 magic 数据库的参数。诊断白名单控制命令名和参数，开启重定向后仍可写文件。

命令通过 Bash 语法树检查，不修改原始命令。引号或转义中的普通字符不会被误判为操作符。开启高危拦截时检查直接命令、管道各节点、命令替换以及可解析的 `bash -c` / `eval` 内容，也检查常用包装命令后的实际命令。已知拒绝项包括 `rm`（所有参数形式，不限于 `-rf`）、`unlink`、`rmdir`、`shred`、`truncate`、`dd`、`mkfs*`、分区工具、系统关机重启、进程终止，以及 `find` 的删除 / 执行动作。无法确定的动态命令名、语法错误和过深嵌套会被拒绝。

这是静态操作保护，不是操作系统沙箱。外部脚本、Python 等任意解释器代码、远程可执行文件内容和环境无法完整检查；这些代码仍可能删除文件或执行其他高危动作。交互终端输入为分段字节流，不经过命令检查，允许 MCP 交互终端后不能宣称高危命令始终被阻止。桌面交互终端由用户直接操作，只读保护会阻止其新输入。删除保护只限制文件删除接口，不约束所有 Shell 行为。

旧设置没有 `command_policy` 时按原开关恢复原行为：原高危拦截开启对应严格诊断模式，原开关关闭对应原有开放模式。设置页首次保存时将独立权限写入 SQLite，后续切换高危拦截不会联动改变这些权限。`list_servers` 的 `security.command_policy` 返回实际生效的独立配置，`security.command_protection` 仅表示高危拦截开关。全局只读、审批和服务器的逐工具权限继续生效。

设计依据：[OWASP 命令注入防护](https://cheatsheetseries.owasp.org/cheatsheets/OS_Command_Injection_Defense_Cheat_Sheet.html) 中的命令和参数白名单原则；不将过滤器描述为完整沙箱。

## 审批

敏感操作包括文件写入、精确编辑、上传、新建目录、重命名、删除、执行命令、打开终端，以及 MCP 的终端输入。`edit_file` 同时要求读取文本和精确编辑授权，受全局只读保护与审批约束；旧配置不会自动获得新权限。桌面交互终端打开后不会逐字符审批；如需禁用交互操作，应开启只读保护。

编辑审批显示提交的 old_text/new_text 列表（最多 8,192 个字符），内容大小和 SHA-256 对应类型化编辑请求的 JSON。完整请求和服务器配置共同绑定到单次审批。审计仅记录编辑数量、写入字节和结果，不持久化替换原文、新文本或 diff。同一服务器配置的文件修改在审批后串行执行，获锁后重新校验权限与策略；该锁不控制远端外部进程。

请求等待桌面用户明确批准或拒绝，最长 120 秒。审批弹窗显示服务器、账户、来源、操作、路径或完整命令；文本写入显示前 8,192 个字符与截断提示，上传和输入显示请求内容大小和 SHA-256。上传的大小及哈希针对 Base64 请求内容。终端输入以转义文本显示，避免隐藏控制字符。

批准只对原始请求执行一次，不产生可复用权限。服务器配置改变会使审批失效；执行前再次校验当前权限和安全设置。拒绝、超时、客户端取消或应用退出均不会执行。队列最多 16 项，普通请求的内容合计上限为 96 MiB；超过该大小的单次传输允许独占内容预算，避免自定义大文件上限被审批队列固定值阻止。重复未处理请求不会重复入队。审批决策先写审计日志，日志写入失败则不放行。

批准与拒绝会产生独立的审批记录，包含原始操作、请求来源、服务器地址、SSH 账户、路径或完整命令、重命名目标、申请及处理时间、有效期、请求编号，以及提交内容的大小和 SHA-256。文件正文不写入审计。记录来源沿用原始请求，因此 MCP 发起的审批可在「MCP」筛选中查到；拒绝明确显示为「已拒绝」并纳入失败筛选。点击记录可查看格式化详情，重启后仍保留。

操作记录页的筛选标签右侧显示当前结果条数，随分类与搜索变化。

桌面窗口处于托盘时，新请求会恢复窗口供用户处理；即使状态刷新设为手动，审批队列仍独立刷新。审批只能通过桌面命令处理，MCP 不提供批准接口。无桌面的 headless 服务如开启审批，将因无人处理而超时拒绝。

## 文件查看

点击文件先打开只读预览，可再选择编辑或下载。文本最多显示前 2 MiB，并受下载上限约束，截断时明确提示；编辑会另行读取完整文本，仍受原有文件读取上限约束。支持 PNG、JPEG、GIF、WebP 图片，不完整或超过上限的图片需下载。

类型通过文件内容识别。HTML、SVG 等文本只作为纯文本展示，不执行脚本、不嵌入 iframe；其他二进制返回不支持预览的提示。预览沿用服务器根目录、符号链接检查及主机指纹验证。正文和图片内容不写入审计日志。
