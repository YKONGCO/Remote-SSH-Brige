# 安全控制

桌面 IPC 和 MCP 请求通过共同后端入口校验服务器状态、权限、安全设置与主机指纹。前端按钮禁用仅作提示，实际控制由后端执行。

## 默认设置

| 功能              | 默认值 | 范围                                                          |
| ----------------- | ------ | ------------------------------------------------------------- |
| 只读保护          | 关闭   | 禁止文件修改、命令执行、终端打开和输入                        |
| 删除保护          | 开启   | 同时阻止桌面 SFTP 删除和 MCP `remove_path`，不约束 Shell 删除 |
| 危险命令拦截      | 开启   | 拦截可静态解析的删除、磁盘破坏、关机等已知高危命令            |
| 审批模式          | 关闭   | 开启后仅审批 MCP 发起的敏感操作，桌面操作不弹审批             |
| 新服务器 MCP 权限 | 读取   | 写入、编辑、安全删除、命令和终端动作需分别授权                |

只读模式仍允许查看、下载、读取终端输出、调整尺寸和关闭终端。审批不能覆盖权限拒绝、只读保护、删除保护或命令拦截。传输大小在进入审批队列前检查。

## 凭据与连接

密码和私钥口令保存在操作系统凭据库，不写入 SQLite 或 MCP 发现结果。配置保存私钥路径，私钥文件由用户自行管理。

SSH 连接校验固定的 SHA-256 主机指纹。首次信任前需通过服务器控制台或管理员核对；地址或端口变化后清除原信任。

MCP 默认监听 `127.0.0.1`，使用 Bearer Token，校验 IP Host 并拒绝浏览器 Origin 请求。每次启动更换 Token。跨不可信网络使用 VPN 或 HTTPS 代理；HTTP 本身不加密传输。

## 命令与 Shell 权限

「设置 → 命令与 Shell 权限」仅保留四项：

| 条目                | 默认值                       | 范围                                                     |
| ------------------- | ---------------------------- | -------------------------------------------------------- |
| 命令执行范围        | 仅允许白名单                 | 禁止执行／仅允许白名单／不限命令                         |
| 命令名单管理        | 内置常用命令白名单、空黑名单 | 分类追加、搜索点选、批量填写；黑名单优先                 |
| 允许 Shell 高级功能 | 关闭                         | 统一控制管道、组合命令、重定向、命令替换、变量和脚本执行 |
| 允许 AI 交互终端    | 关闭                         | MCP 打开终端和发送输入，仍需服务器对应授权               |

名单支持换行、空格、中英文逗号或分号分隔，最多各 4096 项，保存时自动去重。只填命令名称或完整路径，不填参数、通配符或 Shell 语法。白名单仅在“仅允许白名单”模式生效，留空时拒绝全部命令；黑名单在白名单和不限命令模式下均生效。命令名称的白名单规则允许不带路径及位于 `/bin/`、`/usr/bin/`、`/sbin/`、`/usr/sbin/` 的同名程序，自定义路径须明确加入白名单。黑名单中的命令名称匹配所有路径下的同名程序；完整路径规则精确匹配。

未显式授权的自定义程序路径返回 `Executable path is outside trusted directories: ...`，与命令名不在白名单区分。默认名单包含 `true`、`false`、`:`、`yes`、`set`、`bash`、`sh`；`:` 是允许的单独命令名，不表示允许其他包含冒号的规则。组合命令、`set -e; ...` 和 `bash/sh` 脚本仍受高级 Shell 权限控制。

例如，把 `grep` 加入白名单并开启 Shell 高级功能后，`ls | grep error` 可以执行；同时将 `grep` 加入黑名单后，该管道仍会被拒绝。可解析的嵌套 Shell 和常用包装命令也会检查名单；不在名单中的包装命令本身同样会被拒绝。

默认白名单按 24 类维护，覆盖文件与系统、文本处理、Python、JavaScript / TypeScript、C/C++/Fortran、Java/JVM、Go、Rust、.NET、PHP、Ruby、Lua、Perl、Swift、Dart、Elixir/Erlang、Haskell/OCaml、Zig、机器学习、科研计算、构建工具、容器、数据库和网络诊断。包括 `python3`、`pip`、`uv`、`conda`、`pytest`、`ruff`、`node`、`npm`、`pnpm`、`tsc`、`jupyter`、`torchrun`、`accelerate`、`tensorboard`、`wandb`、`hf`、`Rscript`、`mpirun`、`squeue` 等；前后端共用 `src/command-presets.json`，命令仍需在远端安装后才能执行。

已有自定义名单不会被覆盖。在“命令名单管理”点击“全选常用命令”可合并全部预设，也可按分类追加或搜索后点选单个命令；已选命令可再次点击取消；全部选中后，全选按钮可取消相应范围的选择，保留自定义命令与黑名单，点击“保存名单”后生效。“恢复默认名单”会替换白名单并清空黑名单。原有诊断命令仍拒绝修改日期、修改主机名、终止网络连接和编译 magic 数据库的参数；Python / Node 等解释器仍需开启“允许高级 Shell”，全局高危拦截仍会拒绝 `rm` 和 `systemctl reboot` 等动作。旧版仅诊断策略保留只读限制。开启高级功能后，重定向和已授权的脚本仍可能写文件。

命令按 Bash 语法树检查，不修改原始命令。高危拦截覆盖直接命令、管道、命令替换、可解析的嵌套 Shell 和常用命令包装；已知拒绝项包括 `rm`、`unlink`、`rmdir`、`shred`、`truncate`、`dd`、`mkfs*`、分区、关机重启、进程终止，以及 `find` 的删除或执行动作。动态命令名、语法错误和过深嵌套会被拒绝。

`server_info(topic=commands)` 按需返回实际生效的配置：`execution_mode` 表示执行范围，`allowed_commands` 和 `blocked_commands` 表示名单，`allow_advanced_shell` 统一控制高级功能，`allow_mcp_terminal` 控制 AI 交互终端。`command_protection` 表示独立的高危拦截开关，“不限命令”不会关闭高危拦截。默认服务器列表不再携带这些规则，拒绝时仅返回本次原因。

旧配置未设置新字段时继续按原来的分项权限执行，不自动放宽权限；界面会标明“旧配置：部分开启”。切换高级功能后，原有 Shell 分项统一开启或关闭，AI 交互终端保持独立。仅修改其他设置不会改变旧命令策略。

**命令策略不是操作系统沙箱。** 外部脚本、任意解释器代码和远程可执行文件内容无法完整静态检查；交互终端输入为分段字节流，不经过命令解析。`exec` 和终端使用 SSH 账户权限，不受 SFTP 根目录限制。

## 文件与安全删除

SFTP 路径及中间符号链接解析后须位于授权根目录内。根目录限制不是操作系统沙箱，无法完全消除其他进程造成的检查到执行竞态。

`remove_path` 默认未授权，必须单独开启。删除保护同时阻止桌面 SFTP 删除和 MCP `remove_path`；关闭保护后，MCP 仍需服务器“文件删除”授权。该保护不约束 Shell，Shell 删除仍由命令策略控制，也不检查交互终端输入。保护开关保留原授权，开启时发现结果隐藏有效删除权限，后端拒绝已有 ID 的删除调用。

安全删除不展开通配符，不跟随最终链接或递归中的链接，禁止删除授权根目录自身和系统顶层目录。非空目录需显式递归；预检上限为 10000 个条目、深度 64，预检失败不执行删除。部分失败报告进度，响应丢失标记结果未知；删除不支持事务回滚，重试前须核验状态。

文本查看通过 read_file 读取 UTF-8，HTML、SVG 仅按纯文本展示，不执行脚本或嵌入 iframe。文件提交与错误处理见 [MCP 工具参考](MCP_TOOLS.md)。

## 人工审批

敏感操作包括写入、编辑、上传、保存下载文件、新建目录、重命名、删除、执行命令、打开终端和 MCP 终端输入。只读保护允许下载，但阻止上传；下载仍受适用的审批策略约束。桌面交互终端不会逐字符审批；需禁用交互操作时开启只读保护。人工审批仅针对 MCP 发起的请求，桌面端手动操作不会进入审批队列。

请求等待桌面用户明确批准或拒绝，等待时间由“审批等待时间”设置（1–120 秒，默认 120 秒），修改仅影响新请求，倒计时结束自动拒绝并移除待审批项，不执行操作。调用方收到 `APPROVAL_TIMEOUT`，与用户拒绝的 `APPROVAL_REJECTED` 区分。审批展示服务器、账户、来源、路径或完整命令；文本和编辑内容最多显示 8192 个字符，上传和输入显示请求内容大小及 SHA-256。上传的大小和哈希针对 Base64 请求内容，终端输入以转义文本显示。删除请求展示递归与缺失处理选项。

以上 Base64 说明只适用于保留的旧式内联调用。文件流工具只提交路径、文件大小、覆盖选项及摘要等参数；审批摘要绑定这些参数，上传时另行检查源文件内容摘要，不把文件正文放入审批队列。MCP 本地上传和下载目录分别授权，默认都不开放，服务器仍须单独授权相应方向及 `transfer`。数据库只记录传输参数和最终结果；所有失败摘要同样不复制文件数据。

批准只对原始请求执行一次，不产生可复用权限。服务器配置改变会使审批失效，执行前重新校验权限与安全策略。拒绝、超时、客户端取消或应用退出均不执行。MCP 请求的审批决策先写审计，写入失败不放行。

队列最多 16 项，普通请求内容合计上限为 96 MiB，超过该大小的单次传输可独占内容预算。重复未处理请求不会重复入队。审批期间不持有文件修改锁。

审批只能通过桌面处理，MCP 不提供批准接口。应用收起到托盘时，新请求会恢复窗口；审批队列独立刷新。无窗口服务开启审批后，敏感请求会因无人处理而超时。

## 审计

审计记录保存在 SQLite，界面随滚动每批加载 50 条历史记录，分类与搜索在数据库中执行。只有 MCP 发起的操作会写入审计；桌面手动操作不再记录，历史手动记录也不再出现在列表、导出和删除范围内。列表仅渲染可视区域附近的记录，不加载返回内容，打开详情时再读取。JSON 导出包含当前分类和搜索条件下的全部记录及其已保存返回内容，通过系统“另存为”对话框选择目录和文件名。

桌面端支持按日期范围批量删除（仅限 MCP 记录），包含首尾两天、全部分类和服务器及未加载的记录。确认弹窗先统计数量，删除限定在该次统计时已有的记录，不影响随后新写入的记录。删除在同一个 SQLite 事务中执行，失败时整体回滚；成功后同步清理内存缓存和详情，删除的记录重启后不会恢复。

记录包含操作类型、目标路径或命令、来源、结果和耗时。命令标准输出、错误输出各最多保存 16 KiB，其他返回预览最多 64 KiB，截断明确标记。列表刷新不携带返回正文，详情按 ID 获取。

凭据、直接读取或下载的文件正文、编辑原文与 diff、终端输入不写入审计。**命令文本和命令打印的内容会记录**，可能包含敏感信息；共享日志前需检查。

审批记录包含请求和处理时间、有效期、服务器与账户、操作范围、结果及内容大小和哈希，不保存文件正文。MCP 发起的审批沿用 MCP 来源，拒绝归入失败筛选，重启后保留。

## 服务器权限分类

服务器界面提供八项权限：文件读取（list_files、stat_file、read_file）、文件写入（write_file、edit_file）、文件删除（remove_path）、命令执行（exec、job）、终端操作（全部六种终端动作）、文件上传、文件下载和端口转发。文件写入自动包含文件读取，取消文件读取会同时取消文件写入。上传、下载自动补充 transfer 管理权限。

端口转发的四个动作分别授权 `port_forward_open/list/read/close`，默认不授权，不能由命令或终端权限推导。监听固定为应用所在电脑的 `127.0.0.1`，远端目标限 `127.0.0.1` 或 `::1`。转发流量可执行写入，因此全局只读禁止创建并关闭已运行的转发；审批开启时，创建需要展示映射并审批。文件根目录与 Shell 命令策略不能检查隧道内的请求。修改服务器配置或撤销权限会关闭相关转发；桌面可以在服务器停用后关闭转发。仅审计映射参数和结果，不记录流量内容。

已有配置的部分授权以半选状态显示，保存其他设置不会补齐权限；明确勾选整组后才授予全部能力。全局删除保护开启时，“文件删除”保留勾选状态但不可切换，支持跳转设置关闭保护。旧配置默认开启的删除保护现在也会阻止 MCP 删除。
