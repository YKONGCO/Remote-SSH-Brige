# 安全控制

桌面 IPC 和 MCP 请求通过共同后端入口校验服务器状态、权限、安全设置与主机指纹。前端按钮禁用仅作提示，实际控制由后端执行。

## 默认设置

| 功能              | 默认值     | 范围                                                 |
| ----------------- | ---------- | ---------------------------------------------------- |
| 桌面删除保护      | 开启       | 阻止桌面 SFTP 删除；MCP `remove_path` 由独立授权控制 |
| 危险命令拦截      | 开启       | 拦截可静态解析的删除、磁盘破坏、关机等已知高危命令   |
| 只读保护          | 关闭       | 禁止文件修改、命令执行、终端打开和输入               |
| 审批模式          | 关闭       | 可选仅 MCP 敏感操作，或所有来源的敏感操作            |
| 新服务器 MCP 权限 | 读取和预览 | 写入、编辑、安全删除、命令和终端动作需分别授权       |

只读模式仍允许查看、下载、读取终端输出、调整尺寸和关闭终端。审批不能覆盖权限拒绝、只读保护、桌面删除保护或命令拦截。传输大小在进入审批队列前检查。

## 凭据与连接

密码和私钥口令保存在操作系统凭据库，不写入 SQLite 或 MCP 发现结果。配置保存私钥路径，私钥文件由用户自行管理。

SSH 连接校验固定的 SHA-256 主机指纹。首次信任前需通过服务器控制台或管理员核对；地址或端口变化后清除原信任。

MCP 默认监听 `127.0.0.1`，使用 Bearer Token，校验 IP Host 并拒绝浏览器 Origin 请求。每次启动更换 Token。跨不可信网络使用 VPN 或 HTTPS 代理；HTTP 本身不加密传输。

## 命令与 Shell 权限

「设置 → 命令与 Shell 权限」中各项独立控制：

| 开关              | 默认值 | 范围                                               |
| ----------------- | ------ | -------------------------------------------------- |
| 仅允许诊断命令    | 开启   | 每个执行节点须在诊断白名单中                       |
| 允许管道          | 关闭   | `ls \| head`、`\|&`；逐节点检查                    |
| 允许重定向        | 关闭   | 文件与描述符重定向、here-document、here-string     |
| 允许组合命令      | 关闭   | 分号、换行、`&&`、`\|\|`、后台执行和命令分组       |
| 允许脚本执行      | 关闭   | 解释器、脚本路径、变量和控制结构；需关闭诊断白名单 |
| 允许命令替换      | 关闭   | `$(...)`、反引号和进程替换；内层命令仍检查         |
| 允许 MCP 交互终端 | 关闭   | MCP 打开终端和发送输入，仍需服务器对应授权         |

例如，允许管道并保持诊断白名单时，`ls | head` 可执行，`ls | grep error` 因 `grep` 不在白名单被拒绝。单独开启管道不会允许重定向、脚本或组合命令。

诊断白名单包括 `pwd`、`ls`、`cat`、`head`、`tail`、`stat`、`file`、`du`、`df`、`free`、`uptime`、`whoami`、`id`、`uname`、`date`、`hostname`、`ps`、`ss`、`netstat`、`wc`、`readlink` 和 `realpath`。允许不带路径或位于 `/bin/`、`/usr/bin/` 下的同名命令，并拒绝修改日期、修改主机名、终止网络连接和编译 magic 数据库的参数。开启重定向后，诊断命令仍可能写文件。

命令按 Bash 语法树检查，不修改原始命令。高危拦截覆盖直接命令、管道、命令替换、可解析的嵌套 Shell 和常用命令包装；已知拒绝项包括 `rm`、`unlink`、`rmdir`、`shred`、`truncate`、`dd`、`mkfs*`、分区、关机重启、进程终止，以及 `find` 的删除或执行动作。动态命令名、语法错误和过深嵌套会被拒绝。

`list_servers.security.command_policy` 返回实际生效的独立配置，`command_protection` 表示高危拦截开关。未显式设置独立策略时，根据 `block_dangerous_commands` 选择严格或开放默认策略；设置页保存后各项独立生效。

**命令策略不是操作系统沙箱。** 外部脚本、任意解释器代码和远程可执行文件内容无法完整静态检查；交互终端输入为分段字节流，不经过命令解析。`exec` 和终端使用 SSH 账户权限，不受 SFTP 根目录限制。

## 文件与安全删除

SFTP 路径及中间符号链接解析后须位于授权根目录内。根目录限制不是操作系统沙箱，无法完全消除其他进程造成的检查到执行竞态。

`remove_path` 默认未授权，必须单独开启。桌面删除保护只控制桌面 SFTP 删除，不阻止已授权的 `remove_path`，也不约束 Shell；Shell 删除仍由命令策略控制。

安全删除不展开通配符，不跟随最终链接或递归中的链接，禁止删除授权根目录自身和系统顶层目录。非空目录需显式递归；预检上限为 10000 个条目、深度 64，预检失败不执行删除。部分失败报告进度，响应丢失标记结果未知；删除不支持事务回滚，重试前须核验状态。

文件预览按内容识别类型，HTML、SVG 仅按纯文本展示，不执行脚本或嵌入 iframe。文件提交与错误处理见 [MCP 工具参考](MCP_TOOLS.md)。

## 人工审批

敏感操作包括写入、编辑、上传、新建目录、重命名、删除、执行命令、打开终端和 MCP 终端输入。桌面交互终端不会逐字符审批；需禁用交互操作时开启只读保护。

请求等待桌面用户明确批准或拒绝，最长 120 秒。审批展示服务器、账户、来源、路径或完整命令；文本和编辑内容最多显示 8192 个字符，上传和输入显示请求内容大小及 SHA-256。上传的大小和哈希针对 Base64 请求内容，终端输入以转义文本显示。删除请求展示递归与缺失处理选项。

批准只对原始请求执行一次，不产生可复用权限。服务器配置改变会使审批失效，执行前重新校验权限与安全策略。拒绝、超时、客户端取消或应用退出均不执行。审批决策先写审计，写入失败不放行。

队列最多 16 项，普通请求内容合计上限为 96 MiB，超过该大小的单次传输可独占内容预算。重复未处理请求不会重复入队。审批期间不持有文件修改锁。

审批只能通过桌面处理，MCP 不提供批准接口。应用收起到托盘时，新请求会恢复窗口；审批队列独立刷新。无窗口服务开启审批后，敏感请求会因无人处理而超时。

## 审计

审计记录保存在 SQLite，界面列出最近 500 条，完整历史可按 ID 查看。支持分类、搜索、详情、复制和 JSON 导出。

记录包含操作类型、目标路径或命令、来源、结果和耗时。命令标准输出、错误输出各最多保存 16 KiB，其他返回预览最多 64 KiB，截断明确标记。列表刷新不携带返回正文，详情按 ID 获取。

凭据、直接读取或下载的文件正文、编辑原文与 diff、终端输入不写入审计。**命令文本和命令打印的内容会记录**，可能包含敏感信息；共享日志前需检查。

审批记录包含请求和处理时间、有效期、服务器与账户、操作范围、结果及内容大小和哈希，不保存文件正文。MCP 发起的审批沿用 MCP 来源，拒绝归入失败筛选，重启后保留。
