# 使用指南

## 命令白名单

需要扩充命令白名单时，打开「设置 → 安全控制 → 管理名单」：可点击「全选常用命令」，或按 Python、JavaScript、C/C++、Java、Go、Rust、机器学习等分类追加；选择分类或搜索后可点选单个命令。再次点击已选命令可取消选择；全选按钮在全部选中后切换为取消全选。搜索时，本组全选仅作用于当前分类的搜索结果。全局取消全选保留自定义命令，黑名单不受影响，点击「保存名单」后生效。手工粘贴支持换行、空格、逗号和分号，保存时自动去重，每份名单最多 4096 项。输入区可拖动右下角调整高度。运行 Python / JavaScript 脚本还需开启「允许高级 Shell」。

## 服务器

服务器支持新增、编辑、删除、分组、搜索、停用和连接测试。认证方式包括密码、本地私钥和 SSH Agent；私钥路径必须是绝对路径，不自动展开 `~`。

首次连接前，通过服务器控制台或管理员核对 SHA-256 主机指纹，再在应用中确认信任。修改主机地址或端口后会清除原指纹信任，需要重新核验。

桌面操作使用 SSH 账户权限，MCP 访问还需在服务器编辑窗口单独授权。关闭 MCP 访问会隐藏该服务器并拒绝已知 ID 的调用；停用服务器会阻止后续操作，但不会自动终止已有终端，仍可在桌面关闭会话。

MCP 操作权限分为文件读取、文件写入、文件删除、命令执行、终端操作、文件上传、文件下载和端口转发八项。旧配置的部分权限显示为“部分授权”，保存不会自动补齐；勾选整项后才授予其中全部工具。文件写入自动包含读取，取消读取会同时取消写入。

在「端口转发」页面点击「新建转发」，选择服务器和远端端口。本地端口填 0 自动分配，也可指定未占用端口。创建后使用列表中的 `127.0.0.1:端口` 访问远端服务；本地地址位于运行应用的电脑，浏览器预览只模拟状态。列表同时展示桌面和 MCP 创建的转发、连接数、双向流量及最近错误，并提供关闭按钮。需要 Agent 管理时，在服务器的 MCP 权限中勾选「端口转发」。远端目标限服务器自身回环地址，仅支持 TCP；重启应用不会恢复转发。

「设置 → 安全控制」中的删除保护同时禁止桌面和 MCP 的文件删除，默认开启。服务器原删除授权会保留，界面标明“受全局删除保护限制”，可跳转设置关闭保护；关闭后 MCP 仍需服务器的文件删除授权。该保护不限制 Shell 命令或终端中的删除，也不阻止覆盖、编辑和重命名。

## 文件管理

桌面文件页使用 SFTP 浏览目录、创建文件与目录、重命名、删除，以及单文件上传和下载。文件根目录限制 SFTP 路径，并校验符号链接。

下载文件时先打开系统“另存为”对话框，可以选择保存目录并修改文件名；取消对话框不会开始远程下载。操作记录的 JSON 导出也使用相同的保存方式，导出范围为当前分类和搜索条件下的全部记录。

操作详情展示输入参数与返回结果。输入记录实际消费的参数（包括默认值），支持命令、路径、读取范围、后台任务游标及传输参数；MCP 的查询和读取调用也会留下记录。命令输出和长参数按上限保留预览，并标记截断。文件正文、图片和传输数据不写入数据库，文本写入与编辑仅记录参数及内容字节数。旧记录未保存输入时会明确提示，JSON 导出包含新记录的输入与输出。

点击文件通过 read_file 打开 UTF-8 文本只读视图，再选择编辑或下载。图片及其他二进制文件需下载后查看。HTML、SVG 等文本按纯文本展示，不执行脚本。编辑器另行读取完整文本，受下载上限约束。

上传和下载上限支持 MiB / GiB，0 表示不限文件大小，默认沿用各 128 MiB。实际文件通过后端文件流读写，内存只保留固定大小的分块缓冲；进度列表显示大小、速度、阶段和结果，并可取消。文本编辑另有 256 MiB 内存保护。文件保存使用同目录临时文件及原子提交；远端需支持对应 OpenSSH SFTP 扩展。提交结果未知时应先读回核验，不能直接假定失败并重试。详见 [MCP 工具参考](MCP_TOOLS.md)。

MCP 文件传输还需为服务器授权 `upload_file` / `download_file` 和 `transfer`，并在设置中配置各方向的本地授权目录。路径属于运行此应用的电脑；目录留空则禁止 MCP 访问本地文件。数据库和 MCP 结果只记录参数与结果，不保存文件内容。

在「设置 → 远程文件」中管理 MCP 本地上传或下载目录时，可点击「选择文件夹」打开系统目录选择器，支持一次选择多个目录。所选目录追加到编辑区并去除重复项，点击「保存目录」后才生效；取消选择不改变现有内容。仍支持手动填写绝对路径，浏览器预览仅支持手动填写。

## 终端

桌面和 MCP 共用持续连接的 SSH PTY 会话，可保留工作目录、环境变量和交互进程。终端页支持切换会话、调整尺寸、全屏和关闭。

会话列表按设置中的刷新频率更新，进入终端页时立即同步。切换终端标签或服务器时，保留已打开终端的画面、滚动位置和读取进度，并记住每台服务器上次选中的会话。标签支持左右方向键及 Home / End 切换。前台持续读取输出，后台标签降低读取频率。

读取失败会先自动重试，连续失败后可点击「重试读取」，继续从原读取进度同步；此操作不重新执行命令。连接结束后保留输出并禁用输入，可点击「新建连接」创建新会话。活跃会话关闭前需要确认，已结束的会话可直接移除。大段粘贴会分块按顺序发送；输入发送失败不会自动重发。

默认最多保留 32 个会话，可设置为 1–64；降低上限不会关闭已有会话。每个会话保留最近 1 MiB 输出，更早输出可能被覆盖。

会话依赖应用进程和 SSH 连接存活，不支持断网重连或跨应用重启恢复。停止 MCP 不会关闭桌面终端。终端使用 SSH 账户的 Shell 权限，不受 SFTP 根目录限制。

## 窗口与托盘

应用采用单实例模式，重复启动会恢复已有窗口。默认关闭窗口时收起到托盘，MCP 服务和终端继续运行；可在「设置 → 常规 → 关闭窗口时」改为直接退出。

标题栏的收起托盘按钮始终隐藏窗口。点击托盘图标恢复窗口；托盘菜单中的「退出应用」会结束应用和后台服务。

## 设置

连接超时可设为 1–120 秒，SSH 读写超时和默认命令超时可设为 1–300 秒。设置保存后用于后续操作；命令可用 `timeout_secs` 覆盖默认值。

在“设置 → 安全控制 → 审批等待时间”选择 1、5、10、15、30、60 或 120 秒（默认 120 秒）。超时自动拒绝操作。修改仅影响新审批请求，正在等待的请求保留原截止时间。

「命令超时后保留为后台任务」默认关闭。开启并为服务器单独授权 `job` 后，超时的命令保持原 SSH 连接，可用 `job` 的 `list`、`read`、`close` 查看状态、增量输出或关闭会话。每台服务器最多 4 个活动后台任务，每路输出保留最近 4 MiB，结束后保留 30 分钟；修改开关不影响已保留会话。退出应用后无法恢复这些会话，关闭连接不保证远端派生进程终止。接口详见 [MCP 工具参考](MCP_TOOLS.md)。

桌面左侧的「后台任务」栏目位于「操作记录」上方，默认显示运行中的保留会话，可按状态、服务器或命令搜索。点击条目查看标准输出和错误输出；输出以字节游标增量读取，详情关闭后后台任务继续运行。列表随设置中的刷新频率更新，也可使用顶部刷新按钮。关闭会话需确认，只断开该次 SSH 连接，不发送 `kill`。本地用户仍可查看和关闭已停用或删除服务器的保留会话，MCP 访问继续按当前服务器权限校验。

主题、密度、动效、启动页、刷新间隔及终端外观保存在本机浏览器存储。桌面业务设置保存在 SQLite；浏览器演示的业务设置仅在页面内存中保存。

## 数据与备份

Remote SSH Brige 的服务器配置、主机指纹、权限、业务设置和审计记录保存在 Tauri 应用数据目录中的 `remote-desk.sqlite3`，当前数据库 schema 为 v2。登录密码和私钥口令单独保存在系统凭据库，服务名为 `dev.remotedesk.ssh`，条目名为服务器 ID。数据库文件、应用数据目录和凭据服务使用稳定的内部标识，不随显示名称更改。

备份前从托盘退出应用，再复制数据库。运行中可能存在 `-wal` 和 `-shm` 文件，请勿只复制正在使用的主数据库文件。数据库备份不包含系统凭据库中的密码，也不包含私钥文件。

## 功能范围

当前不支持跳板机、SSH config 导入、递归目录传输、逐字符终端审批或操作系统级命令沙箱。远程文件系统上的外部进程竞态无法完全消除；请结合 [安全控制](SECURITY_CONTROLS.md) 配置权限。
