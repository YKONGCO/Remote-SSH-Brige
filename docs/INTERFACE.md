# 界面更新

- 自定义窗口栏替代原生标题栏，可拖拽、最小化、最大化、还原、收起到托盘。
- 关闭窗口和系统关闭请求均收起到托盘，不结束服务和终端。托盘左键恢复，右键提供显示与退出。
- 移除独立命令执行页面；MCP 的 exec 工具保留。
- 服务器页改为紧凑列表，保留搜索、分组、连接测试、文件、终端与连接编辑。
- 移除统计卡片、推广区、头像、装饰页脚、英文小标题与重复标语。
- 精简文件、终端、操作记录和 MCP 配置页面；界面说明采用中文，协议名、路径和用户自定义名称保持原值。
- 统一控件高度、边框、圆角和间距。正文 13 像素、字段和表格 12 像素，必要的辅助标签 11 像素。

验证：前端生产构建、界面流程测试、自定义窗口按钮测试、Rust 桌面编译，以及原生窗口关闭隐藏 / 进程保留 / 托盘点击恢复检查。

## shadcn/ui

基础组件来自 shadcn/ui 官方 new-york 注册表，源码保存在 src/components/ui，使用 Tailwind CSS 与 Radix。已应用 Button、Input、Textarea、Dialog、Tabs、Checkbox、Select、DropdownMenu、Badge。components.json 保留后续添加组件的配置。主题统一为中文紧凑布局。

滚动条在主内容区、列表、弹窗、编辑器、下拉菜单和终端中隐藏；保留原有溢出与滚动行为，没有通过禁止滚动来隐藏滚动条。

已补充验证弹窗关闭后的焦点恢复、认证标签键盘切换、权限勾选、下拉菜单和环境筛选。

## 配色与字体

- 主色为 #0071e3；正文 #1d1d1f，次级文字 #6e6e73，必要的弱提示 #86868b。页面使用中性浅灰、白色卡片和灰色细边框，减少偏蓝灰和过浅文字。
- 界面字体优先级：SF Pro SC、SF Pro Text、系统苹果字体、PingFang SC、Helvetica Neue、Arial、Microsoft YaHei UI、Microsoft YaHei。标题优先 SF Pro Display。终端和代码保持等宽字体。
- 官网字体栈参考苹果中国主页及其 main.built.css；项目没有下载、内嵌或远程加载苹果字体文件。本机未安装 SF Pro / 苹方，当前 Windows 使用可用的系统回退字体，不能称为已内置苹果字体。
- 4 项界面测试、前端构建和桌面编译通过，已检查实际桌面截图。

## 操作详情与单实例

操作详情使用 620 像素的居中弹窗，带视口宽高限制，详情内容可滚动。通用弹窗使用明确的内联尺寸约束，避免 Tailwind 通用类覆盖宽度。元数据改为紧凑排列，增加命令标准输出、错误输出、退出码、通用返回及复制。旧记录没有输出时明确提示，不伪造历史结果。

返回预览保存在审计中，命令每路输出最多 16 KiB，其他返回最多 64 KiB，截断保留标记。列表刷新不传返回正文，打开详情按 ID 获取。直接文件正文、下载二进制和终端输入不写入审计。

桌面入口首先注册官方单实例插件，按固定应用标识检测。重复启动恢复已有窗口并结束第二进程。通过同路径及不同目录的原生重复启动测试，也验证了托盘隐藏后恢复。此机制从新版生效，升级时需先退出没有单实例插件的旧版。

## SQLite 与紧凑列表

服务器配置、权限、主机指纹与操作记录改为 SQLite 存储。旧 JSON 和 JSONL 在首次启动的事务中一次性导入，保留原文件和服务器 ID，凭据仍存系统凭据库。界面只显示最近 500 条，数据库保留完整已导入及新增历史；详情可按 ID 查询。

服务器行高约 60 像素，名称 12 像素、地址 11 像素，操作按钮 25 像素；文件和操作记录表格减小单元格间距，环境与状态标签同步收紧。未改变滚动、焦点或键盘操作。

## 窄窗口布局

- 小于等于 1050 像素时，侧栏收为带悬停名称和可访问标签的图标导航；宽窗口保留文字导航。
- 操作记录使用固定表格列布局，长命令 / 路径省略，不再把时间列挤出视口。时间分为日期与时分秒两行。
- 中等窗口把来源放在服务器第二行；更窄时把服务器 / 来源放进操作信息，耗时放在结果下，详情仍保留完整信息。
- 筛选、搜索、导出在窄窗口自动分行。文件工具栏、文件表格及终端标签支持窄窗口重排。
- 桌面最小窗口宽度调整为 800、高度为 600 像素。
- 使用独立应用标识和虚构数据完成实际窗口验收，没有操作现有服务器或中断正式实例。800、960、1200 像素内容宽度均无横向溢出，时间列显示完整。

## 固定头部与终端工作区

窗口栏高度为 36 像素。页面标题栏移出滚动容器，高度为 56 像素，窄屏为 52 像素。普通页面仅正文滚动；操作记录的筛选区和表格列头也固定。

终端页使用统一顶部工具栏：标题、服务器选择、刷新、新建；移除重复的新建入口与独立会话数量栏。会话标签和关闭按钮分开，标签可横向滚动，全屏入口固定在右侧。终端正文通过剩余空间布局，不再依赖整个视口高度的固定减法，连接状态保持在终端底部。

原生滚动测试确认操作记录和设置页面标题在滚到末尾前后位置一致；操作记录筛选区和表头位置一致。终端窄屏截图检查通过，且只存在一个新建按钮。
